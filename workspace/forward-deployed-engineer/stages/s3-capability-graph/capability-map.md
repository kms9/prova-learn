# S3 能力地图

> focus：怎样把 FDE 课程和已审计证据转成可诊断、可迁移的工作应用能力？

## 一级能力与二级子能力

| Capability | 可观察能力 | Sub-capability | 子能力 |
|---|---|---|---|
| `CAP-001` | 用产物、责任和产品回流区分 FDE 与相邻角色 | `SC-001A` | 建立角色边界证据矩阵 |
| `CAP-001` | 同上 | `SC-001B` | 判断何时应/不应使用 FDE 模式 |
| `CAP-002` | 把模糊诉求转成高价值问题 | `SC-002A` | 观察工作流、基线、干系人与决策权 |
| `CAP-002` | 同上 | `SC-002B` | 写价值假设、选择问题与停止条件 |
| `CAP-003` | 设计真实约束下的最小可行部署 | `SC-003A` | 收敛 MVD 架构、数据、集成和权限边界 |
| `CAP-003` | 同上 | `SC-003B` | 设计上下文评估、治理、go/no-go 与回滚 |
| `CAP-004` | 规划上线、采用、续约和扩展闭环 | `SC-004A` | 区分技术、采用、业务和复用四层证据 |
| `CAP-004` | 同上 | `SC-004B` | 用健康信号决定激活、续约、扩展或收缩 |
| `CAP-005` | 产品化现场学习并识别退出风险 | `SC-005A` | 把重复现场模式回流产品/平台 |
| `CAP-005` | 同上 | `SC-005B` | 监测定制趋势，决定退出、交接或转平台 |
| `CAP-006` | 审查课程案例和统计的证据等级 | `SC-006A` | 区分 provenance、独立来源组和证据角色 |
| `CAP-006` | 同上 | `SC-006B` | 审计主张、置信度、适用边界与刷新条件 |

## 角色深度阶梯

| 层级 | 对应能力 | 自主性与复杂度 | 影响与责任 | 掌握深度 | 来源 |
|---|---|---|---|---|---|
| guided contributor | `CAP-003` | 在给定问题和边界下完成 MVD 子任务 | 对工件质量和已分配风险负责 | 能解释并应用既定评估/回滚规则 | `SRC-101`,`SRC-102`,`SRC-105` |
| independent FDE | `CAP-002` | 独立从模糊工作流定义问题和停止条件 | 对跨干系人范围、价值和生产闭环负责 | 能诊断伪需求并迁移到新场景 | `SRC-101`,`SRC-102`,`SRC-104` |
| lead/productizing FDE | `CAP-005` | 处理跨客户共性、治理冲突和商业约束 | 对复用、退出、团队续航和产品反馈负责 | 能建立标准并判断何时停止高强度定制 | `SRC-101`,`SRC-104`,`SRC-110` |

职级差异通过自主性、复杂度、影响、责任和迁移要求表达，不复制一套“专家术语”。
