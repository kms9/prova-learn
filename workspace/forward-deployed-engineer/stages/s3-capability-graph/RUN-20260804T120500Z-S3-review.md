## 3. 建模焦点与设计原则

焦点问题：**怎样把 FDE 课程和已审计证据转成可诊断、可迁移的工作应用能力，使学习者能在陌生企业 AI 场景作出可辩护的部署判断？**

设计原则：

1. 从六项终局能力反推真实任务，再拆分子能力、学习单元和原子节点；
2. 层级、单元覆盖和先修分别建模，不用展示顺序冒充硬先修；
3. 一个语义只保留一个规范 node_id，横切证据能力复用映射；
4. 每个节点有误概念、测评、事前阈值、迁移要求和补救入口；
5. 来源只证明任务结构，不作为岗位/书/论文式目录；
6. S3 结构稳定，个性化学习顺序留给 S4/S5。
