排查结论：真正负责“根据个性化学习理论选择策略”的主阶段是 S5；把策略落实成教学交互的是 S6。 S4 和 S7 分别提
  供选择依据与效果反馈。S1/S3 负责目标及认知层级对齐，S2 负责理论证据取证，但都不应直接决定教学方法。

  ### 不同理论具体应该落在哪里

  布鲁姆分类学

  它主要是目标与测评的“认知复杂度分类”，不是一种教学方法。Krathwohl 的修订版说明
  (https://www.gvsu.edu/cms4/asset/EF4BB85F-CE60-13B2-48C316794B210EBA/krathwohl_revised_blooms_taxonomy%282%29.pdf)也是把它作为认知过程维度。

  因此应该贯穿：

  - S1：明确目标是记忆、理解、应用、分析、评价还是创造。
  - S3：给节点测评标认知层级。
  - S5：保证教学活动和退出标准达到目标层级。
  - S6：生成对应层级的活动。
  - S7：检验该层级是否真的达成。

  目前仓库已经部分采用 Bloom，但存在明显的不一致：

  - S1 使用“记忆、解释、应用、诊断、迁移、创造”：.agents/skills/create-goal-success-contract/SKILL.md:27
  - S3 使用 explain/apply/diagnose/evaluate/transfer/remember：.agents/skills/build-capability-concept-
    graph/references/stage-contract.md:76

  - S6 使用标准修订版 remember/understand/apply/analyze/evaluate/create：.agents/skills/run-instructional-
    interaction/references/stage-contract.md:63

  也就是说，目前缺少一套跨 S1/S3/S5/S6/S7 的统一认知层级语义映射。

  建构主义/建构式学习

  它强调学习者基于已有知识主动构造新理解，因此跨越三个阶段：

  - S4：发现学习者已有概念、误概念与解释模型。
  - S5：判断某节点是否适合探究、对比案例、项目或协作建构。
  - S6：让学习者预测、解释、操作、比较、反思，而不是只接收答案。

  当前 S4 已经要求解释、预测、反例、诊断、比较与迁移任务，.agents/skills/diagnose-learner-frontier/
  references/stage-contract.md:45与建构式诊断比较吻合。但 S5 尚未明确记录“选择建构式策略的理由和适用条件”。

  苏格拉底提问

  它是教学/诊断方法，不是与建构主义同层级的完整学习理论。其核心是用结构化提问检查假设、理由、证据和推论，USC
  的教学说明
  (https://stem-ed.usc.edu/our-research/eerp/socratic-questioning/)也将其定义为基于提问与讨论的策略。

  适用位置：

  - S4：诊断学习者的推理链和误概念。
  - S6：作为渐进提示、反例追问和反思对话。
  - S7：通过无提示追问判断理解是否稳定。

  它不应成为默认全局模式。对缺乏基础图式的新手，如果只追问而不给必要示例，容易提高额外认知负荷。这种情况下应
  由 S5 先选择 worked example 或直接解释，再由 S6 逐步转入苏格拉底提问。

  费曼学习法

  更适合作为“解释生成/teach-back 技术”，而不是独立学习理论：

  - S4：让学习者用自己的话解释，用于暴露理解缺口。
  - S6：要求面向初学者解释、去除术语依赖，再接受反例追问。
  - S7：无提示解释加未见任务，可作为掌握证据之一。

  它不能单独证明掌握：一个人可能说得通顺但不会应用，因此必须与应用、诊断、迁移和延迟保持证据结合。

  worked example、检索、间隔、交错

  这些属于认知科学支持的教学/练习策略：

  - S5 决定何时安排。
  - S6 执行 worked example、检索前测和渐隐练习。
  - S7 安排间隔、交错和延迟复测。

  这与当前合同一致：.agents/skills/plan-learning-sessions/references/stage-contract.md:62、.agents/skills/ru
  n-instructional-interaction/references/stage-contract.md:49、.agents/skills/verify-mastery-and-replan/refe
  rences/stage-contract.md:75。这些策略也有较明确的研究基础，例如 IES/WWC 教学实践指南
  (https://ies.ed.gov/ncee/wwc/PracticeGuide/1)与间隔和检索练习综述
  (https://doi.org/10.1038/s44159-022-00089-1)。

  ### 当前最主要的设计缺口

  现在的 S5 已经规定“根据概念类型、错误类型和认知目标匹配教学策略”，这是正确的阶段归属；但 Schema 只允许：

  explain / worked_example / practice / retrieval / interleaving / transfer / delayed_retest / contrast_case

  见 .agents/skills/plan-learning-sessions/references/learning-and-session-plan.schema.json:87。

  这里存在四个问题：

  1. 混合了不同层级：worked_example 是教学技术，interleaving 是练习编排，transfer 是目标/证据类型，
     delayed_retest 是测评安排。



  ### 建议的最终归属

  不需要新增第八阶段。当前进行中的 S3 扩展也明确规定：S3 只负责稳定结构，个性化的 introduce/reinforce/review
  顺序仍归 S5/S6，openspec/changes/add-outline-knowledge-mapping-to-s3/design.md:41。

  最合理的闭环是：

  S2 收集理论及实证证据
  → S3 标记知识类型与认知目标
  → S4 产出学习者状态和误概念信号
  → S5 选择理论、方法及切换规则
  → S6 执行方法并记录过程
  → S7 判断效果，失败时返回 S5 重选策略

  因此，如果后续要补需求，核心变更应放在 S5 的策略选择合同，同时扩展 S6 的执行轨迹和 S7 的效果归因；S3 只需
  要统一认知层级与知识类型，不应该成为教学理论选择器。
