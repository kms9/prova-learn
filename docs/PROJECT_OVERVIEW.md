# Prova Learn 项目说明

## 项目定位

Prova Learn 是一个基于 Agent Skill 架构的证据驱动型个性化学习系统。

它尝试解决传统 AI 学习助手中的核心问题：

- 只生成学习内容，而无法证明学习是否发生；
- 只根据用户自述判断掌握，而缺少行为证据；
- 只执行固定流程，而无法根据学习结果动态调整。

Prova Learn 将学习过程设计为一个可验证、可回溯、可重规划的闭环。

## 核心理念

学习目标不是“完成课程”，而是形成可观察的能力。

系统通过以下链路运行：

```text
目标定义
  ↓
领域知识取证
  ↓
能力模型构建
  ↓
学习者诊断
  ↓
学习路径规划
  ↓
教学交互
  ↓
掌握验证
  ↓
重新规划
```

## 设计特点

### 1. Evidence-driven

所有关键判断都需要基于证据。

例如：

- 学习者表示“我会了”不是掌握证据；
- 一次答对不能代表长期掌握；
- 真正掌握需要结合独立任务、迁移任务、保持测试等信息。

### 2. Skill 化阶段能力

系统将学习流程拆分为多个可组合 Skill，每个阶段拥有明确输入、输出和验证规则。

这种设计使学习流程可以：

- 独立测试；
- 替换升级；
- 复用到不同领域。

### 3. Fail Closed

当缺少必要信息时，系统不会自动假设成功。

例如：

- 缺少学习者反馈；
- 缺少真实任务表现；
- 缺少验证证据。

流程会进入 pending 或 blocked 状态。

## 适用场景

当前设计主要面向：

- 技术技能学习；
- 职业能力提升；
- 个性化训练系统；
- AI Tutor / Learning Agent 构建。

## 与普通 AI Tutor 的区别

| 普通 AI Tutor | Prova Learn |
| --- | --- |
| 生成解释和练习 | 构建完整学习闭环 |
| 关注内容生成 | 关注能力形成 |
| 根据对话推断学习效果 | 根据行为证据验证 |
| 固定课程路径 | 动态诊断和规划 |

## 项目愿景

Prova Learn 希望探索一种新的 AI 学习系统范式：

> AI 不只是回答问题，而是帮助学习者建立能力，并持续验证能力是否真正形成。
